# Android Projects

Collection of small Android apps built with Jetpack Compose while learning Android development. Kotlin + Compose only, no XML views.

## Projects

| Project | Description |
|---|---|
| [Affirmations](./Affirmations) | Scrollable list of affirmation cards with images |
| [Article](./Article) | Simple article/text layout app |
| [CoursesApp](./CoursesApp) | Grid of courses using LazyVerticalGrid |
| [DiceRoller](./DiceRoller) | Dice roll simulator with state handling |
| [GreetingCard](./GreetingCard) | Basic Compose layout and theming intro |
| [Lemonade](./Lemonade) | Multi-step tap interaction app (lemonade stand) |
| [Quadrant](./Quadrant) | Four-quadrant layout using Compose UI basics |
| [Superheroes](./Superheroes) | List of superheroes using LazyColumn and cards |
| [TaskManager](./TaskManager) | Task/to-do list app with state management |
| [TipCalculator](./TipCalculator) | Bill tip calculator with input handling |
| [WoofApp](./WoofApp) | Dog list app with expandable cards and animations |

## Stack

- Kotlin
- Jetpack Compose
- Material 3

## Structure

Each folder is a standalone Android Studio project. Open individually, sync Gradle, run.

## Requirements

- Android Studio (latest stable)
- Min SDK per project (check each `build.gradle.kts`)
